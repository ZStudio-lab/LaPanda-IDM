Setting up

Four steps, about two minutes

  1. Install LaPanda IDM

    Grab the installer from the trial page — it is the same file, and buying a licence does not change it. Windows will ask you to approve the install, because it writes to Program Files. Then press Install. It goes into your Program Files folder and adds a Start menu entry.

  2. Launch LaPanda IDM

    Open LaPanda IDM from the Start menu. The installer is not code-signed yet, so Windows SmartScreen will warn you. Choose More info, then Run anyway, on both the installer and the app. If the .NET 8 Desktop Runtime is not already installed, the installer offers to fetch it.

  3. Copy your machine ID

    The activation window shows a machine ID for this computer. Use Copy request and keep it — it is what identifies your licence, and we cannot issue a key without it.

  4. Email us, then paste the key

    Email studiozerith@gmail.com with your machine ID from the same address you ordered with. We reply with your licence key; paste it into the activation window and LaPanda IDM is ready. The key stays valid on this computer through a Windows reinstall.

If something goes wrong

  • Email studiozerith@gmail.com with your order email address and a description of the problem.
  • Keep your machine ID. It is the first thing we will ask for, and without it we cannot issue a key.
  • Your licence is bound to the machine it is activated on. Moving to a new computer needs a reissued key, which we do at no cost.
