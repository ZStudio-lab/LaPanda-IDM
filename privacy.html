1. The application sends nothing

LaPanda IDM does not collect, transmit or disclose usage data of any kind. Specifically, there is no:

  • analytics, telemetry, or usage measurement of any kind;
  • crash reporting or error-reporting service;
  • remote licence check, activation server, or “phone home” routine;
  • automatic update check that contacts a server to ask whether a newer version exists;
  • account, sign-in, or user profile of any kind;
  • advertising identifier, device fingerprint transmitted anywhere, or marketing tag.

Licence entitlement is proved by verifying a cryptographic signature against a public key compiled into the executable. That check is entirely local and completes in microseconds, which is why no licence server exists to be unavailable.

2. Network connections it does make

Privacy claims are only useful if they acknowledge the traffic that genuinely happens. The application makes outbound connections to the following, and nothing else:

  • The hosts you download from. The URLs you supply, together with the HTTP range and resume headers needed to transfer the file. This is the transfer itself, and those hosts see your IP address as any web server does.
  • An HTTP or proxy server you configure. If you set a proxy in Settings, your requests are routed through it, and it necessarily sees the destination URLs.
  • dot.net, once, during installation. If the .NET 8 Desktop Runtime is missing and you accept the installer’s offer, the installer fetches Microsoft’s official dotnet-install.ps1 script over HTTPS from https://dot.net/v1/ and runs it. Declining the offer skips this entirely.
  • Windows Defender, locally. Completed files are passed to the Defender scanner already installed on your machine. This does not leave the computer.
  • BitTorrent trackers, in future. If torrent support is exposed in a later version, announces go to the trackers named in the torrent file and your peer ID is disclosed to them. This is not active in version 1.0.

The application never makes inbound connections, so it does not require a firewall rule to function. If your firewall prompts you, denying the prompt costs you nothing.

The licence key is stored in plain text on purpose. It cannot be forged, only copied, and a copied key still has to pass both the signature check and the machine binding on every launch. Encrypting it locally would obscure that without adding meaningful protection.

The uninstaller asks before removing %APPDATA%\IDM, so reinstalling never silently discards your queue or your licence.

The trial clock is deliberately kept outside that folder. It is recorded in more than one place, at least one of which the uninstaller does not touch, so uninstalling and reinstalling does not give you a second 30-day trial. Each copy carries a checksum keyed to your machine's hardware identifier, so a date edited by hand is detected and the trial is treated as finished rather than reset.

We want to be straightforward about the limit here: this is software that never contacts a server, so everything the trial check relies on is stored on your own machine, and someone with local administrator access and enough patience can eventually get around any purely offline check. That is a property of offline software in general, not a specific flaw we are sitting on. We record the clock more than once and verify it so that the ordinary cases, uninstalling, reinstalling, restoring an old backup, and editing a file in a text editor, all behave correctly on their own without you having to think about them.

4. This website

These pages are static files. They are served as-is, with no content management system, no database and no server-side code.

  • No third-party requests. No analytics service, advertising network, tag manager, embedded video, social widget, web font or CDN is loaded. System fonts are used instead, which is also why the page renders identically offline.
  • No cookies are set. The site sets no cookies at all.
  • One piece of local storage, and it is optional. If you tell the page whether you are in India, your answer is kept in your browser’s localStorage so the site can show the right currency next time. It never leaves your browser, is not linked to you, and clearing your browser data removes it. Decline the question and nothing is stored.
  • No region detection service. Where you are is inferred from your own browser settings — your time zone and language — entirely on your machine. No IP lookup, no geolocation request, no third-party service.
  • Server logs. Whoever hosts these files may keep ordinary web server logs (IP address, user agent, requested path). That is a property of the hosting arrangement, not something the page does.

6. The machine ID

When you request a licence, the application shows a machine ID: a 32-character hexadecimal string. It is a SHA-256 hash, truncated, of values read from your computer’s BIOS (system manufacturer, product name, baseboard manufacturer and product, family) together with the system volume serial number.

It is not a name, an email address, a hardware serial number that identifies you personally, or a location. It cannot be reversed into the values it was built from, and it does not identify your computer to anyone who has not seen it.

The MAC address is deliberately excluded, because laptops routinely switch between Wi-Fi and Ethernet and including it would silently invalidate a paid licence. You send this ID yourself, by email, as part of a purchase or support request. It is not transmitted automatically by the application.
